# Chapter 11: Design A News Feed System

Design a Facebook-style news feed system.

## Key Topics
- Feed publishing flow
- News feed building flow
- Fanout service:
  - Fanout on write (push model)
  - Fanout on read (pull model)
  - Hybrid approach (celebrities use pull, regular users use push)
- Cache architecture:
  - News feed cache
  - Content cache (hot/normal)
  - Social graph cache
  - Action cache
  - Counter cache
- News feed retrieval API (pagination via cursor)
- Web servers, notification, fanout workers, message queue
